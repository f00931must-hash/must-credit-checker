# 明新科技大學資源教室學分檢核系統

第一版畫面與計算流程雛形。

## 示範登入

- 學生姓名：測試學生
- 學號：DEMO0001

示範模式使用瀏覽器內的虛擬資料，不會讀寫 Firebase，也不包含真實學生資料。

## 已完成的雛形功能

- 學生姓名＋學號查詢介面
- 老師／小幫手的學生清單
- 四類學分進度總覽（分類通識併入校必修）
- 依年級及上下學期查看課程
- 分辨尚未修習及曾修習未通過（不顯示分數）
- 分類通識四領域與12學分警示
- 時序表外／外系課程待確認與人工認列
- 轉系等情況可人工調整學分類別
- 外系學分12學分認列上限
- 手機版畫面

## 安全狀態

- 老師與小幫手由資源教室入口的授權名單控制。
- 老師只能存取自己 `ownerEmail` 工作區的學生。
- 小幫手只能存取所屬老師 `ownerEmail` 工作區，可新增、修改及刪除學生資料。
- `firestore-bootstrap.rules` 只供首次建立管理員；完成同步後必須立即改回正式 `firestore.rules`。
