# 明新科技大學資源教室學分檢核系統

第一版畫面與計算流程雛形。

## 示範登入

- 學生姓名：測試學生
- 學號：DEMO0001

示範模式使用瀏覽器內的虛擬資料，不會讀寫 Firebase，也不包含真實學生資料。

## 已完成的雛形功能

- 學生姓名＋學號查詢介面
- 老師／小幫手的學生清單
- 四類學分進度總覽（分類通識併入校必修）
- 依年級及上下學期查看課程
- 分辨尚未修習及曾修習未通過（不顯示分數）
- 分類通識四領域與12學分警示
- 時序表外／外系課程待確認與人工認列
- 轉系等情況可人工調整學分類別
- 外系學分12學分認列上限
- 手機版畫面

## 安全狀態

- 老師與小幫手由資源教室入口的授權名單控制。
- 老師只能存取自己 `ownerEmail` 工作區的學生。
- 小幫手只能存取所屬老師 `ownerEmail` 工作區，可新增、修改及刪除學生資料。
- `firestore-bootstrap.rules` 只供首次建立管理員；完成同步後必須立即改回正式 `firestore.rules`。

## v1.2.0

- 時序表依老師 `ownerEmail` 工作區分開，小幫手共用所屬老師的時序表。
- 貼上成績前先指定年級／學期，只在該學期內比對同名課程。
- 人工分類及查詢範圍增加大五至大八。

## v1.3.0

- 上傳時序表後先預覽 PDF 各頁，預選可能的中文課程表頁面，再由老師確認辨識範圍。
- 人工調整增加取消認列，可恢復時序表課程為尚未修習。

## v1.3.1

- 0學分必修課程可正常保留、辨識與顯示。
- 時序表外或無法自動對應的成績課程一律進入待人工分類，不阻擋整批匯入。

## v1.4.0

- 修正學生更換時序表時，舊課程空值造成 Firestore 拒絕更新。
- 人工認列可修改為0至9學分，支援0.5學分級距及9學分實習。

## v1.4.1

- 時序表內課程再次辨識成績時，學分以老師最新版時序表為準，AI只判斷是否通過。
- 已完成課程的操作名稱改為「調整認列／學分」，可直接修正既有學分。

## v1.4.2

- 小幫手工作區改以入口同步的 `ownerEmail` 判斷，不再依賴特定角色名稱。
- 修正小幫手可讀取老師時序表，但新增學生時被 Firestore 拒絕的問題。

## v1.4.3

- 新增學生不再預先讀取尚不存在的文件，避免 Firestore 規則誤擋小幫手。
- 鎖定既有學生的工作區、學號與建立時間，防止新增操作覆蓋既有資料。

## v1.4.4

- 刪除時序表前會列出所有仍綁定的學生姓名與學號。
- 移除刪除檢查對複合索引的依賴；有學生使用時仍保留時序表與學生資料。

## v1.4.5

- 支援「學分抵免、抵免、免修、合格」等完成狀態；0學分課程仍可標記完成。
- 無法判定的成績狀態不再中止整批辨識，改送至待人工審查。

## v1.4.5.1

- 修正 v1.4.5 成績匯入程式的括號錯誤，恢復網站登入與全部按鈕功能。
